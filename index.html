지표 정의(v4.4.1)
- 평균CPC = 총예산 / 총클릭
- 평균CPA = 총예산 / PaidDB(전환)
- CVR = PaidDB / 총클릭
- ROAS(실매출 기준) = 실매출 / 총예산
- DB당 가치 = 해당기수 실매출 / 해당기수 모집DB(=Owned+Paid)
- 예상매출 = 이전기수 DB당 가치 × 현기수 모집DB(누적)
